# CMPE341 – Operating Systems Project  
## Employee Lifecycle Sync System

This project is developed as part of the **CMPE341 – Operating Systems** course.  
The goal of the project is to implement a simple **employee lifecycle automation** system using **Bash scripting** on a Linux environment.

The script reads employee information from a CSV file and automatically manages Linux users and groups based on the employee status.

---

## Project Objective

The main objectives of this project are:
- To practice Linux user and group management
- To understand process automation using shell scripts
- To work with files (CSV parsing) in Bash
- To apply operating system concepts in a real scenario
